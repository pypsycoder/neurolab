# MCP: test-only contracts 1.6

**Статус:** подэтапы 1.6.1–1.6.2 выполнены; внешний MCP transport не
подключён.

До появления реальных серверов НейроЛаб использует только проверяемую policy
модель трёх test-only контрактов: поиск по документации, чтение заранее
разрешённого synthetic fixture и diff ограниченного набора путей репозитория.

Каждый вызов проходит allowlist имени, точную схему параметров и ограничения
путей до того, как мог бы быть передан transport. Shell, сеть, произвольные
URL, секреты, абсолютные пути, traversal и range Git вне `HEAD` запрещены.
Ответ инструмента всегда помечается как недоверенные данные; текст из него не
может становиться инструкцией агенту.

Проверки покрывают неизвестный tool, лишние аргументы, traversal, неразрешённый
Git range и prompt injection. Никакие ключи, patient data или внешний
web-search этим подэтапом не включаются.

Локальный `stdio` test server реализован на официальном Python SDK MCP 2.2.0.
Он объявляет ровно эти три имени инструментов, применяет тот же policy gate и
возвращает исключительно synthetic-результаты. В частности, обработчики не
читают файловую систему, не запускают Git, не обращаются к сети и не читают
`.env`. End-to-end test запускает его отдельным дочерним процессом, проверяет
список инструментов и маркировку ответа как недоверенного.

Следующий подэтап — добавить отдельные negative transport-tests, а затем
спроектировать независимо ревьюируемую sandbox-реализацию операций только над
fixture-репозиторием. До этого этот сервер не является доступом к файлам,
Git или внешним MCP-серверам.
