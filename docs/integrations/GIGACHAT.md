# GigaChat: контракт интеграции 1.1

**Проверено:** 2026-09-13  
**Режим:** исследовательский, только публичные и синтетические данные.

## Выбранный способ

- Язык: Python 3.11.
- SDK: официальный пакет `gigachat` 0.2.3 (зафиксирован для воспроизводимости).
- Базовый URL: `https://api.giga.chat/v1`.
- Авторизация: ключ из переменной `GIGACHAT_CREDENTIALS`; ключ не записывается
  в код, тестовые фикстуры, логи или документацию.
- TLS: проверка включена. Её отключение запрещено этим проектом.
- Scope: задаётся явно в `GIGACHAT_SCOPE`; значение должно совпадать с ключом.

SDK получает и обновляет access token сам при использовании credentials. Для
первой живой проверки запрашивается список моделей; это подтверждает
аутентификацию, доступность endpoint и разрешения, не отправляя содержательных
данных в модель.

## Режимы проверок

| Проверка | Сеть | Ключ | Назначение |
|---|---|---|---|
| Unit | Нет | Нет | Конфигурация, запрет пустого ключа, TLS и базовый URL |
| Live models | Да | Да, только в окружении | Аутентификация, endpoint, список моделей |
