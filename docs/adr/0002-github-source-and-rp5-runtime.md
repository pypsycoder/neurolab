# ADR-0002: GitHub как источник кода, Raspberry Pi 5 как среда запуска

**Статус:** accepted  
**Дата:** 2026-09-13  
**Владелец:** владелец проекта (пользователь)  
**Пересмотр не позднее:** до подключения реальных данных или production-контура

## Контекст

Владелец проекта определил Raspberry Pi 5 (RP5) как единственную среду, где
код НейроЛаба должен запускаться, тестироваться, коммититься и отправляться в
удалённый репозиторий. Администрирование RP5 выполняется через SSH/Tailscale.

## Решение

1. GitHub-репозиторий является источником версионируемого кода и документации.
2. RP5 является рабочей средой `dev/test`; существующая рабочая копия и
   Compose проект НейроЛаба в `/opt/neuro-lab` — целевой контур для связи с
   GitHub. Локальная среда разработчика не хранит runtime-секреты и не
   используется для живых запросов GigaChat.
3. Ключи GigaChat и будущие секреты существуют только на RP5 в локальном
   окружении/секретном хранилище и никогда не добавляются в Git.
4. `.gitignore` обязателен для `.env`, ключей, сертификатов и локальных
   артефактов. До первого push проверяется отсутствие секретов среди
   отслеживаемых файлов.
5. Доступ к RP5 выполняется только через настроенный SSH/Tailscale endpoint;
   пароль и закрытые ключи не передаются в чат или репозиторий.

## Видимость и ограничение

GitHub сообщил, что для аккаунта недоступны private repositories. Владелец
проекта создал публичный репозиторий `pypsycoder/neurolab` и разрешил
публикацию безопасного стартового каркаса. Публичность означает, что в него
допускаются только код, тесты с синтетическими данными и не чувствительная
документация; секреты, персональные данные, внутренние логи и `sources/`
строго запрещены.

## Проверка и критерий отката

До публикации: подтвердить видимость репозитория, проверить `.gitignore` и
отсутствие секретов. На RP5: проверить Tailscale/SSH, Git state и Compose state
в `/opt/neuro-lab`, безопасно связать существующую рабочую копию с GitHub,
затем выполнить тесты и opt-in live GigaChat тест.
